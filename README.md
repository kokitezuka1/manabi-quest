# 学びクエスト（manabi-quest）

小学5年生向け「勉強したくなる」ソシャゲ風 Web アプリ。ビルド不要の静的サイト（HTML/CSS/JS）で、データはブラウザの localStorage に保存。

## 遊ぶ

https://kokitezuka1.github.io/manabi-quest/

## 手元で起動

```bash
python3 -m http.server 8765
```

http://localhost:8765 を開く（`index.html` を直接開いても動く）。

## ゲームの流れ

| 仕組み | 内容 |
|---|---|
| タイマー | 科目と目標時間（5〜60分）を選んで開始。途中休憩可・リロードしても継続。1回の記録は最大120分 |
| 報酬 | 1分ごとに ⭐1・経験値10。目標達成で経験値×1.2・⭐+5 |
| キャラ育成 | ファンタジーRPG風の仲間18体。パートナーが勉強時間で成長し、得意教科なら EXP×1.5。Lv10・Lv25で進化 |
| 世界一周の冒険 | アメリカ（太平洋岸・山岳部・中西部・南部・南東部・北東部の36都市。ハワイ・アラスカを含む31州とワシントンD.C.）→ヨーロッパ→中東→アジアの全54都市を回る。各都市に土地にちなんだ弱点教科（例：フィラデルフィア＝社会、セントルイス＝算数）があり、その教科を勉強するとダメージ×2。各地域の6都市で6教科が1回ずつ登場 |
| 豆知識 | 都市に到着すると、その街の豆知識が読めるようになる。地図から都市をタップしていつでも読み返せる |
| ガチャ | ⭐30 or 🎫1で1回、⭐270で10連（★★以上1体確定）。30回で★★★確定。被りはEXPに変換 |
| おうちの人との約束 | 保護者ページで決めた1日の目標時間と残り時間をホームに表示。達成で⭐+20。優先教科には「おすすめ」の印がつき、⭐×1.5 |
| 毎日 | 連続日数ボーナス、デイリーミッション4つ＋全クリアボーナス、カレンダーのスタンプ（💮=30分以上） |

## 保護者ページ

https://kokitezuka1.github.io/manabi-quest/parent.html （ゲームの ⚙️設定 →「保護者ページを開く」からも開ける）

- その日の勉強時間（合計・教科ごと・開始〜終了時刻）を確認。前の日にもさかのぼれる
- 最近7日間の勉強時間と目標達成日数、教科のバランス
- 1日の目標学習時間（平日／土日）と、優先して学習させたい教科を設定
- 4桁の暗証番号（PIN）でロックできる

### 保護者と子どもの連携（Firebase）

`js/firebase-config.js` に Firebase の設定を書くと、アカウントで連携できるようになる（未設定なら、データはブラウザ内だけにあり、お子さまがゲームで使っている端末・ブラウザで保護者ページを開く必要がある）。

1. 保護者は保護者ページで Google アカウントにログインし、6桁の連携コード（10分有効）を出す
2. お子さまはゲームの ⚙️設定 →「保護者と連携する」でコードを入力（お子さまのアカウントは不要。匿名ログイン）
3. 以後、勉強の記録は自動でクラウドに保存され、保護者はどの端末からでも確認・設定できる。目標時間と優先教科はゲームに自動で届く
4. 子どもの端末はいくつでも連携できる（最大10台）。どの端末でもクラウドの最新の記録から続けられ、2台で同時に使ったときは勉強の記録を両方残し、⭐や冒険の進み具合は新しく保存された方に合わせる
5. 保護者も、同じ Google アカウントならどの端末からでもログインできる

Firebase の準備：
1. [Firebase コンソール](https://console.firebase.google.com/)でプロジェクトを作る
2. Authentication → ログイン方法で「Google」と「匿名」を有効にし、設定 → 承認済みドメインに `kokitezuka1.github.io` を追加
3. Firestore Database を作成（本番環境モード、ロケーションは asia-northeast1 など）し、ルールに `firestore.rules` の内容を貼って公開
4. プロジェクトの設定 → マイアプリ → ウェブアプリを追加し、表示された `firebaseConfig` を `js/firebase-config.js` に貼る

開発時は `npx firebase emulators:start --project demo-manabi` でエミュレーターを起動し、URL に `?emulator=1` をつけて開くと手元で試せる。

## ファイル

- `js/data.js` … 教科・キャラ・都市（豆知識）・称号・ミッションなどのマスターデータ（バランス調整はここ）
- `js/icons.js` … キャラと敵のアイコン（game-icons.net）
- `js/maps.js` … 冒険マップの地形データ（Natural Earth から生成）
- `js/store.js` … セーブデータとゲームルール（経験値計算・ダメージ・ガチャ抽選）
- `js/fx.js` … 効果音（WebAudio で合成、音声ファイルなし）・紙吹雪
- `js/app.js` … 画面描画
- `parent.html` / `js/parent.js` / `css/parent.css` … 保護者ページ
- `js/cloud.js` / `js/firebase-config.js` / `firestore.rules` … 保護者と子どもの連携（Firebase）

## 更新時の注意

JS/CSS を変えたら、`index.html` の `?v=7` の数字を上げる（ブラウザの古いキャッシュを使わせないため）。
